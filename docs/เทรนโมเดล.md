# คู่มือการเทรนโมเดลจับท่ามวย (Model Training User Manual)
**เวลาที่ใช้** ครั้งแรก ~30 นาที (รวมติดตั้ง) · ครั้งต่อไป ~10 นาที

---

## ภาพรวม 4 ขั้น

```
1. เก็บข้อมูล        ที่แดชบอร์ดบนมือถือ/แท็บเล็ต — ต่อยจริงให้ระบบดู
        ↓            ได้ไฟล์ .csv
2. เทรน              บนคอมพิวเตอร์ — คำสั่งเดียว
        ↓            ได้ไฟล์ strike_web_model_fine.json
3. อัปโหลดกลับ        ที่แดชบอร์ด — โมเดลไปเก็บใน SD ของเครื่อง
        ↓
4. ใช้งาน             ทุกมือถือที่ต่อเข้ามาได้โมเดลใหม่อัตโนมัติ
```

**ทำไมต้องเทรนบนคอม** — ESP32 บนเครื่องแรมไม่พอเทรนโมเดล และเทรนบนมือถือจะใช้เวลา
เป็นสิบนาที เครื่องทำหน้าที่เก็บข้อมูลกับใช้งานโมเดล ส่วนการเทรนทำบนคอมครั้งเดียว

ต้องมี **Python 3.10 หรือ 3.11** บนคอม (เวอร์ชันใหม่กว่านี้ TensorFlow อาจยังไม่รองรับ)

เช็คว่ามีหรือยัง:

```bash
python3 --version
```

ติดตั้งไลบรารีที่ใช้:

```bash
cd ~/Documents/GitHub/StrikeSense/ml_pipeline && pip3 install -r requirements.txt
```

ใช้เวลาสักพัก (TensorFlow ไฟล์ใหญ่) เสร็จแล้วไม่ต้องทำอีก

## ขั้นที่ 1 · เก็บข้อมูล

### เตรียมเครื่อง

1. เปิดโหนดเซนเซอร์ **ครบทั้ง 4 ตัว** (มือซ้าย · มือขวา · แข้งซ้าย · แข้งขวา)
   ใส่ครบสำคัญ เพราะแขนขาที่ไม่ได้ออกอาวุธจะถูกบันทึกเป็นท่า "ขยับตัว" ให้อัตโนมัติ
   ซึ่งเป็นข้อมูลที่ทำให้ระบบไม่นับการก้าวเท้าเป็นการเตะ
2. ต่อ WiFi ชื่อ **StrikeSense** แล้วเปิด `192.168.4.1`
3. ไปแท็บ **ระบบ** → เปิดสวิตช์ **โหมดนักพัฒนา**
   จะมีแผง **เก็บข้อมูลเทรน AI** โผล่ขึ้นมา

### เก็บทีละท่า

```
1. เลือกท่าจากช่องเลือก        เช่น "หมัดเสย"
2. กด "เริ่มบันทึก"
3. ออกอาวุธท่านั้น ~50 ครั้ง
4. กด "หยุดบันทึก"             ระบบจะบอกว่าเก็บได้กี่ครั้ง
5. เลือกท่าถัดไป → ทำซ้ำข้อ 2-4
```

**กติกาตอนอัด — สำคัญกว่าที่คิด**

| ทำ | ทำไม |
|---|---|
| **ออกอาวุธเต็มแรงทุกครั้ง** | ระบบนับเฉพาะที่แรงเกิน 6 g ถ้าซ้อมเบา ๆ ให้ครบจำนวน จะได้ข้อมูลไม่ถึงครึ่ง |
| **สลับซ้าย-ขวา** | ถ้าใช้ข้างเดียว มืออีกข้างที่ตั้งการ์ดนิ่ง ๆ จะถูกป้ายเป็นท่านั้นไปด้วย ทำให้ระบบสับสน |
| **ก้าวเท้าขยับตลอด** | ได้ข้อมูล "ขยับตัว" ไปด้วย ถ้ายืนตรึงจะไม่ได้เลย |
| **เว้นจังหวะระหว่างครั้ง ~0.5 วินาที** | ถ้าเร็วกว่านี้ระบบจะนับรวมเป็นครั้งเดียว |

### ดูว่ายังขาดท่าไหน

ใต้แผงมีคลังข้อมูลบอกความคืบหน้าสด ๆ:

```
คลังข้อมูลที่เก็บไว้
เตะตัด        ████████████  72
แย็บ          ███████       45/50
ศอกงัด        ██            12/50   ← ยังขาดอีก 38
```

แถบเขียว = ครบ 50 ครั้งแล้ว · ตัวเลขคือ **จำนวนครั้งที่ต่อยจริง** ไม่ใช่จำนวนข้อมูลดิบ

**50 ครั้งต่อท่า** คือจุดที่วัดแล้วว่าความแม่นเริ่มเชื่อถือได้ ท่าที่มี 130 ครั้งขึ้นไปได้ความแม่น
89-97% ส่วนท่าที่มีต่ำกว่า 35 ครั้งตัวเลขยังเหวี่ยงมากจนสรุปอะไรไม่ได้

### ส่งออก

กด **"↓ ส่งออกทั้งหมด"** — ได้ไฟล์เดียวลงโฟลเดอร์ Downloads

> ⚠ **ข้อมูลอยู่ในหน่วยความจำเบราว์เซอร์ ปิดแท็บแล้วหาย**
> เก็บเสร็จกดส่งออกก่อนปิดทุกครั้ง

## ขั้นที่ 2 · เทรน

เอาไฟล์จาก Downloads มาที่คอม แล้วรันคำสั่งเดียว:

```bash
cd ~/Documents/GitHub/StrikeSense && ./ml_pipeline/retrain.sh
```

สคริปต์จะหาไฟล์ใหม่ใน Downloads เอง ย้ายเข้าคลังข้อมูลให้ แล้วเทรน
ใช้เวลาราว 3-6 นาที

**ตัวเลือกอื่น**

```bash
./ml_pipeline/retrain.sh ~/Downloads/ไฟล์ที่ต้องการ.csv   # ระบุไฟล์เอง
./ml_pipeline/retrain.sh --no-import                      # เทรนจากข้อมูลเดิมเฉย ๆ
```

### อ่านผลลัพธ์

จบแล้วจะได้ตารางแบบนี้:

```
ท่า            โมเดล   +กายภาพ
Hook          100.0%    100.0%
Uppercut       95.6%     98.8%
Jab            97.6%     97.6%
Cross          88.5%     88.5%
Elbow-Slash    50.0%     60.0%   ← ต่ำ
```

ตัวเลขคือ **ระบบจับท่านั้นถูกกี่เปอร์เซ็นต์**

| เห็นแบบนี้ | แปลว่า | ทำอะไรต่อ |
|---|---|---|
| 90% ขึ้นไป | ใช้งานได้ดี | ไม่ต้องทำอะไร |
| 70-90% | พอใช้ | เก็บท่านั้นเพิ่มอีก ~30 ครั้ง |
| ต่ำกว่า 70% | ยังเชื่อไม่ได้ | เก็บให้ถึง 50 ครั้ง แล้วเทรนใหม่ |

ถ้าตัวเลขของท่าไหน **เหวี่ยงไปมาทุกครั้งที่เทรน** แปลว่าข้อมูลท่านั้นยังน้อยเกินไป
ไม่ใช่โมเดลมีปัญหา

## ขั้นที่ 3 · อัปโหลดโมเดลกลับ

1. ต่อ WiFi **StrikeSense** → เปิด `192.168.4.1`
2. แท็บ **ระบบ** → หัวข้อ **คลังโมเดล AI**
3. กด **"เพิ่มไฟล์โมเดล"** → เลือกไฟล์:

```
ml_pipeline/strike_web_model_fine.json
```

4. รอจนขึ้นว่า **"พร้อม · N ท่า · เก็บที่ SD card"**

เก็บลง SD ของเครื่องแล้ว — มือถือเครื่องอื่นที่ต่อเข้ามาจะได้โมเดลใหม่เองโดยไม่ต้องอัปซ้ำ

## ขั้นที่ 4 · ตรวจว่าใช้ได้จริง

ในแท็บระบบจะเห็นกล่องบอกว่าโมเดลรู้จักท่าอะไรบ้าง:

> **โมเดลนี้แยกได้ 9 ท่า**
> มือ · แย็บ · หมัดตรง · ฮุก · หมัดเสย · ศอกสับ · ศอกตี · ศอกงัด
> ขา · เตะตัด · เตะขาล่าง

ท่าที่ไม่อยู่ในรายการ (เข่า · ถีบ) ระบบจะตอบเป็นท่าที่ใกล้เคียงที่สุด — เป็นการเทียบเคียง
ไม่ใช่การอ่านค่าจริง ถ้าอยากให้แยกได้จริงต้องเก็บท่านั้นแล้วเทรนใหม่

ลองออกอาวุธดู ชื่อท่ากับคะแนนจะขึ้นที่การ์ดบนสุดของหน้าแรก

## ปัญหาที่เจอบ่อย

**เก็บข้อมูลแล้วนับได้น้อยกว่าที่ต่อยจริงมาก**
ต่อยไม่แรงพอ ระบบนับเฉพาะที่เกิน 6 g ดูตัวเลข "แรง G" บนแถบบนสุด ต้องพุ่งเกิน 6 ทุกครั้งที่ต่อย

**`pip3 install` ไม่ผ่าน / หา tensorflow ไม่เจอ**
Python เวอร์ชันใหม่เกินไป ต้องใช้ 3.10 หรือ 3.11

**เทรนแล้วท่าที่เคยแม่นกลับแย่ลง**
ปกติถ้าตัวอย่างทดสอบของท่านั้นมีน้อย (ต่ำกว่า ~20 ครั้ง) ตัวเลขจะเหวี่ยงเองทุกครั้งที่เทรน
ไม่ใช่การถดถอยจริง ดูที่คอลัมน์จำนวนครั้งประกอบเสมอ

**อัปโมเดลแล้วแต่ชื่อท่าไม่ขึ้น**
เช็คว่าเปิดสวิตช์ "เปิดตรวจจับท่าด้วย AI" แล้วหรือยัง และโหนดที่ใส่ตรงกับอวัยวะที่ตั้งค่าไว้ไหม

**Jab กับ Cross สลับกันบ่อย**
เซนเซอร์อยู่ที่ข้อมือ มองเห็นสองท่านี้เกือบเหมือนกัน ต่างกันที่การหมุนลำตัวซึ่งข้อมือรับได้ไม่เต็ม
เป็นเพดานของฮาร์ดแวร์ ไม่ใช่ของโมเดล ถ้าจำเป็นให้อัดแยกข้าง (มือนำ = แย็บ · มือหลัง = หมัดตรง)
แล้วเทรนด้วยโหมด `coarse_lr` ซึ่งใช้ข้างช่วยตัดสิน
