## 2. ขั้นตอนการเริ่มต้นใช้งาน (Quick Setup)

1. **เปิด Main Node (ESP32-S3)**:
   - เสียบสาย USB หรือต่อแบตเตอรี่เข้า Main Node
   - สังเกตไฟสถานะ **NeoPixel** ติดสว่าง = ระบบ Wi-Fi AP พร้อมใช้งาน
2. **เชื่อมต่อ Wi-Fi บนอุปกรณ์ของลูกค้า**:
   - บนมือถือ แท็บเล็ต หรือคอมพิวเตอร์ ให้เลือกเชื่อม Wi-Fi **`StrikeSense`** (รหัสผ่าน: `muaythai123`)
3. **เปิดหน้าแดชบอร์ด (Web Dashboard)**:
   - เปิดเบราว์เซอร์แล้วพิมพ์ `https://192.168.4.1` (หรือ `http://192.168.4.1`)
   - ระบบอาจเปิดหน้าเว็บอัตโนมัติ (Captive Portal)
4. **เปิดสวิตช์ Strike Nodes (โหนดเซนเซอร์)**:
   - กดปุ่ม Power บน Strike Node แต่ละตัว (สังเกตไฟ LED กระพริบ)
   - สวมโหนดเข้ากับอวัยวะ (มือซ้าย, มือขวา, แข้งซ้าย, แข้งขวา)

## 3. การผูกเซนเซอร์และการตั้งค่าตำแหน่ง (Sensors Management)

ไปที่แท็บ **"เซนเซอร์" (Sensors)** บนหน้าแดชบอร์ด เพื่อตรวจสอบและกำหนดตำแหน่งโหนด:

### 3.1 การตรวจสอบโหนดที่ออนไลน์
- การ์ดแสดงรายการเซนเซอร์จะโชว์ **MAC Address**, **ระดับแบตเตอรี่ (%)**, **ความแรงสัญญาณ (RSSI)** และ **สถานะออนไลน์ (สีเขียว)**

### 3.2 ปุ่มฟังก์ชันในการจัดการโหนด:
- **ปุ่ม "ระบุตำแหน่ง" (Identify / Blink LED)**: กดเพื่อให้เซนเซอร์ตัวนั้นกระพริบไฟ LED เพื่อตรวจสอบว่าคืออุปกรณ์ชิ้นใด
- **ช่องดรอปดาวน์ "กำหนดตำแหน่ง (Slot)"**: เลือกมอบหมายตำแหน่งให้กับเซนเซอร์:
  1. `Left Hand` (มือซ้าย)
  2. `Right Hand` (มือขวา)
  3. `Left Shin` (แข้งซ้าย)
  4. `Right Shin` (แข้งขวา)
- **ปุ่ม "รีบูตโหนด" (Restart Node)**: สั่งรีสตาร์ตเซนเซอร์ตัวนั้นๆ ไร้สาย
- **ปุ่ม "ลืมอุปกรณ์" (Forget)**: ลบการผูกอุปกรณ์ออกจากระบบ

## 4. การใช้งานหน้าจอหลักสำหรับการฝึกซ้อม (Live Training Dashboard)

หน้าหลักของแดชบอร์ดได้รับการออกแบบสไตล์ **"Fight Card"** ให้ข้อมูลสดทันทีเมื่อออกอาวุธ:

### 4.1 แผงวัดพลังและสถิติสด (Live Metrics)
- **Live Velocity & G-Force Graph**: กราฟแสดงเส้นความเร็ว ทิศทาง และแรงกระแทกสดแบบ Real-time
- **Live Impact Power ( Peak G )**: ตัวเลขแสดงค่าแรงปะทะสูงสุดและค่าเฉลี่ยทันทีเมื่อมีการปะทะ
- **Strike Indicator (ระบบไฟระบุท่าทาง)**: ไฟกะพริบขึ้นชื่อท่ามวยไทยทันทีตามอาวุธที่นักมวยออกจริง (เช่น JAB, CROSS, HOOK, UPPERCUT, ELBOW, KNEE, KICK) พร้อม % ความมั่นใจของ AI

### 4.2 หุ่นจำลองการปะทะ (Body Hit Diagram & Heatmap)
- **โหมด LIVE**: หุ่น 4 โซน (LH, RH, LS, RS) แฟลชสีแดงทันทีเมื่ออวัยวะนั้นออกอาวุธปะทะ
- **โหมด HEATMAP**: เปลี่ยนสีหุ่นเป็นเฉดสีแดงตามความถี่ปะทะสะสม ช่วยวิเคราะห์ความสมดุลการใช้อาวุธ

### 4.3 ตัววัดสมรรถภาพเชิงลึก (Performance Insights)
- **Strike Counter**: กล่องดิจิทัลนับจำนวนครั้งการออกอาวุธรวม และแยกประเภทอาวุธ
- **SPM (Strikes Per Minute)**: วัดความเร็วอัตราการออกอาวุธต่อนาที
- **Striking Distribution Pie Chart**: กราฟวงกลมแสดงสัดส่วนการใช้อาวุธ (เช่น หมัด 40%, เตะ 30%, เข่า 30%)
- **Asymmetry Ratio (L:R)**: อัตราส่วนการใช้อวัยวะซ้ายเทียบกับขวา ช่วยโค้ชวิเคราะห์ความสมดุลร่างกาย
- **Fatigue & Consistency Tracker**: กราฟและดัชนีเปรียบเทียบแรงปะทะตั้งแต่ต้นจนจบ เพื่อวิเคราะห์ระดับความเหนื่อยล้า
- **Strike Score (0–100)**: ดัชนีคะแนนประเมินคุณภาพความแรงและจังหวะของแต่ละหมัด

## 5. ระบบนาฬิกาชกเป็นยก (Boxing Round Timer)

ใช้สำหรับควบคุมการซ้อมและจับเวลาชก:

### 5.1 การตั้งค่าเวลา (Presets)
- เลือกรูปแบบเวลา เช่น `3 ยก × 3 นาที (พัก 1 นาที)`, `5 ยก × 3 นาที`, `custom` หรือโหมดจับเวลาอิสระ (`Stopwatch`)

### 5.2 การควบคุมและการบันทึกอัตโนมัติ (Auto-Record)
- ปุ่มกด: **`START`**, **`PAUSE`**, **`SKIP`**, **`RESET`**
- **สวิตช์ Auto-Record (REC)**: หากเปิดไว้ ระบบจะเริ่มบันทึกข้อมูลการซ้อมลง SD Card อัตโนมัติเมื่อเข้าสู่ช่วงชก (Work) และหยุดชั่วคราวช่วงพักยก (Rest)

### 5.3 การปักหมุดโค้ช (Coach Markers)
- กดปุ่ม **`+ MARKER`** (หรือกดปุ่มคีย์บอร์ด **`M`**) เพื่อปักหมุดเวลาและใส่โน้ตข้อความบันทึกจังหวะสำคัญในการซ้อม

## 6. การดูประวัติการซ้อมและการส่งออกข้อมูล (Session Library & Replay)

ไปที่แท็บ **"เซนเซอร์ / ประวัติซ้อม"** บนแดชบอร์ด:

1. **รายการซ้อมย้อนหลัง**: แสดงไฟล์การซ้อมที่บันทึกอยู่ใน SD Card ของ Main Node พร้อมวันที่ ขนาดไฟล์ และชื่อนักกีฬา
2. **ดาวน์โหลด CSV**: กดปุ่ม **"↓ ดาวน์โหลด"** เพื่อเซฟไฟล์สถิติ 400Hz เข้าคอมพิวเตอร์/มือถือ
3. **ดูตัวอย่าง (Preview / Replay)**: กดปุ่ม **"VIEW"** เพื่อโหลดกราฟ สถิติย้อนหลัง และเส้นเวลา (Timeline Strip) ขึ้นมาวิเคราะห์
4. **เปรียบเทียบเซสชัน (Compare)**: ติ๊กเลือก 2 ไฟล์แล้วกด **"COMPARE"** เพื่อเปรียบเทียบความแตกต่างทางกายภาพระหว่างรอบซ้อม
5. **ลบไฟล์**: กดปุ่ม **"DELETE"** เพื่อลบไฟล์ออกจาก SD Card

## 7. โหมดการเก็บข้อมูลเพื่อเทรน AI (Data Logger Mode)

หากต้องการเก็บข้อมูลเพิ่มเพื่อเทรนโมเดล AI ให้จำจำท่าใหม่ๆ ได้แม่นยำยิ่งขึ้น:

### 7.1 ขั้นตอนการเก็บข้อมูล
1. ไปที่แท็บ **ระบบ** → เปิดสวิตช์ **"โหมดนักพัฒนา" (Developer Mode)**
2. ที่แผง **"AI TRAINING · DATA LOGGER"** ทางด้านซ้าย ให้เลือกท่าที่จะบันทึก (เช่น หมัดแย็บ, ฮุค, เตะตัด, แทงเข่า)
3. กด **"เริ่มบันทึก"**
4. ให้นักมวยออก **ท่าเดิมซ้ำๆ ประมาณ 30–50 ครั้ง** (ออกอาวุธเต็มแรง, เว้นจังหวะ 0.5 วินาที)
5. กด **"หยุดบันทึก"**
6. เลือกท่าถัดไป แล้วทำซ้ำข้อ 3–5
7. เมื่อเก็บครบทุกท่า ให้กด **"↓ ส่งออกทั้งหมด"** เพื่อดาวน์โหลดไฟล์ CSV เข้าเครื่อง

## 8. การเทรนและการอัปโหลดโมเดล AI (AI Model Retraining & Upload)

### 8.1 การเทรนโมเดลบนคอมพิวเตอร์ (ทำเพียงคำสั่งเดียว)
นำไฟล์ CSV จากโฟลเดอร์ Downloads มาที่คอมพิวเตอร์ แล้วรันคำสั่ง:

- **สำหรับ macOS / Linux**:
  ```bash
  cd ~/Documents/GitHub/StrikeSense && ./ml_pipeline/retrain.sh
  ```
- **สำหรับ Windows**:
  ```cmd
  cd %USERPROFILE%\Documents\GitHub\StrikeSense && .\ml_pipeline\retrain.bat
  ```
  *(หรือดับเบิลคลิกไฟล์ `retrain.bat` ในโฟลเดอร์ `ml_pipeline` ได้เลย)*

ผลลัพธ์จะได้ไฟล์โมเดลใหม่ชื่อ: `ml_pipeline/strike_web_model_fine.json`

### 8.2 การอัปโหลดโมเดลเข้าใช้งาน
1. เปิดแดชบอร์ด **`https://192.168.4.1`** → ไปที่แท็บ **ระบบ**
2. หัวข้อ **"คลังโมเดล AI"** กดปุ่ม **"เพิ่มไฟล์โมเดล"**
3. เลือกไฟล์ `strike_web_model_fine.json` ที่เพิ่งเทรนเสร็จ
4. ระบบจะบันทึกโมเดลลง SD Card ของ Main Node (`/models/`) และเปิดใช้งานโมเดลใหม่ในเบราว์เซอร์อัตโนมัติ **โดยไม่ต้อง flash เฟิร์มแวร์ ESP32 ใหม่**

## 9. การตั้งค่าระบบและการรีเซ็ต (System Diagnostics & Reset)

ไปที่แท็บ **ระบบ** บนแดชบอร์ด:

- **การปรับแต่งการตรวจจับ (Detection Tuning)**:
  - **G-Force Threshold**: ปรับค่าแรงปะทะขั้นต่ำที่ถือเป็น 1 หมัด/เตะ (ค่าเริ่มต้น 3.0g)
  - **Refractory Window**: ปรับเวลากันนับซ้ำ (ค่าเริ่มต้น 250ms)
- **การรีเซ็ตและการดูแลรักษา**:
  - **รีสตาร์ทไร้สาย (Radio Restart)**: รีเซ็ตสัญญาณ ESP-NOW หากเซนเซอร์หลุด
  - **รีบูตเครื่อง (Reboot)**: สั่งรีสตาร์ตสมองกล Main Node
  - **รีเซ็ตเป็นค่าโรงงาน (Factory Reset)**: ล้างค่าความจำเซนเซอร์และการตั้งค่าทั้งหมด

## 10. ตารางคีย์บอร์ดลัด (Keyboard Shortcuts)

|:---:|:---|
| **Spacebar** | เริ่ม / หยุด การบันทึกซ้อม (REC Toggle) |
| **R** | รีเซ็ตนาฬิกายกซ้อม (Reset Round Timer) |
| **S** | ข้ามช่วงเวลาพัก/ชก (Skip Phase) |
| **M** | ปักหมุดโน้ตโค้ช (Add Coach Marker) |
| **F** | เปิด/ปิด โหมดเต็มหน้าจอ (Toggle Fullscreen) |
| **H** | เปิด/ปิด หุ่นความถี่การปะทะ (Toggle Heatmap) |
| **T** | เปลี่ยนธีม มืด/สว่าง (Toggle Dark/Light Theme) |
| **1 – 4** | กรองสถิติแยกตามเซนเซอร์ slot 1-4 |
| **0** | ดูสถิติรวมเซนเซอร์ทุกจุด |
| **Esc** | ปิดหน้าต่างป๊อปอัป (Close Modal) |
